# 十、常见问题排查

## 1. 节点显示 Timeout 或延迟为 -1

可以依次检查：

- 本地网络是否正常。
- 系统时间是否准确。
- 客户端订阅是否已更新。
- 当前节点是否临时维护。
- 是否误开启了直连或代理规则。

## 2. 订阅链接更新失败

可以尝试：

- 检查订阅链接是否完整。
- 重新复制后台订阅地址。
- 更换网络后再次更新。
- 检查客户端是否支持当前订阅格式。
- 联系机场客服确认订阅服务状态。

## 3. 能连接但网页打不开

可以尝试：

- 切换其他节点。
- 检查客户端 DNS 设置。
- 尝试规则模式与全局模式。
- 更新客户端版本。
- 排查本地网络或 DNS 问题。

## 4. ChatGPT 或其他 AI 平台无法访问

可以尝试：

- 更换美国、日本或新加坡节点。
- 检查当前节点是否支持目标平台。
- 清理浏览器缓存或重新登录。
- 确认平台账户及地区设置是否符合要求。
